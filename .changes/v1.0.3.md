## v1.0.3 - 2026-09-24

- _🤖 CI & Build_: Improve documentation for the setup, making it clear what the container setup section in the sidecar chart is for, which is the user provided container to attach the sidecar too.
- _🤖 CI & Build_: Adjust changie output to use new label format for nicer changelogs.
- _🤖 CI & Build_: Add `minikube:listimages` and `minikube:dashboard` mage tasks from dsv-k8s repo.
- _🤖 CI & Build_: Add reference to updated trunk install setup commands in upstream package instead of outdated one local.
- _🤖 CI & Build_: Release pipeline repaired. The scan workflow now uses golang/govulncheck-action (the old action could no longer build), mage passes goreleaser v2 flags, and the goreleaser config drops a deprecated key. aqua-installer moved to v4.0.3: the old one could no longer verify aqua downloads after a Sigstore key change.
- _🔒 Security_: Bumped the Go toolchain to go1.26.8 and golang.org/x/net to v0.59.0, resolving Snyk-reported vulnerabilities in the Go standard library and x/net.
- _🔒 Security_: google.golang.org/grpc 1.16.0 → 1.83.2, clearing both Snyk CRITICALs. This required replacing the unmaintained github.com/ericchiang/k8s client with k8s.io/client-go.
- _🐛 Bug Fix_: A pod whose `dsv` annotation is removed no longer keeps receiving tokens.
- _⬆️ Dependencies_: Bump trunk tooling.
- _⬆️ Dependencies_: Migrate to goreleaser v2 format, and ensure all the required mage tasks use the correct options.
